## How to run the hardhat node
1. Start the hardhat node:
```bash
npx hardhat node
```

## How to deploy the smart contract

1. Install the required dependencies:
```bash
npm install
```
2. Compile the smart contract:
```bash
npx hardhat compile
```
3. Deploy the smart contract:
```bash
npx hardhat ignition run bridgeDeployment.js
```

<!--- you can set the smart contract address in the config/default.json file -->
